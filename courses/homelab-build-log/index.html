What you need before starting

A spare computer
Any old desktop or mini PC. 4GB+ RAM, any modern CPU. No GPU needed for this path.
USB drive, 8GB+
To flash the Ubuntu Server installer onto and boot from.
Ethernet, or a Linux-friendly WiFi adapter
Wired is simplest. Wireless works too, covered in Phase 4.
A laptop on the same network
This is what you'll SSH in from once the server has no monitor attached.
~$10–20 for a domain
Needed only when you get to Phase 9, making the app public.
Patience with a terminal
Every step here is a typed command. No prior Linux experience assumed.
